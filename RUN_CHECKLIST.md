# Что нужно проверить лично перед сдачей КТ2

- [ ] Распаковать проект с папкой `.git`; убедиться, что `git log --oneline` показывает минимум 2 коммита.
- [ ] Установить Python-зависимости и Chromium по README.
- [ ] Выполнить `python -m pytest tests/test_purchase.py -v --browser chromium`.
- [ ] Зафиксировать фактические результаты TC-01, TC-02, TC-03 в `TEST_CASES.md`.
- [ ] Исправить возможные ошибки, сделать самостоятельный коммит с осмысленным заголовком.
- [ ] Создать публичный GitHub-репозиторий, запушить ветку main, проверить вкладку Actions.
- [ ] Вписать рабочую ссылку GitHub в раздел 3 отчёта и URL коммитов в разделы 4–5.
- [ ] Вписать свои настоящие ФИО/группу, время по этапам и личную оценку роли.
- [ ] Убедиться, что все ссылки открываются в режиме инкогнито без авторизации.
- [ ] Загрузить заполненный .docx на страницу «КТ2. Сдать работу» в Moodle.

**Важно:** ответы о собственном опыте и фактическом времени нельзя заменить
предположениями. Если E2E не прошёл из-за сетевых ограничений, это нужно
описать в отчёте и повторить запуск в доступной среде.
